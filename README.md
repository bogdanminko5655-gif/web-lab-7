# Лабораторна робота №2. Основи Bootstrap — варіант 7

Тема: особистий тревел-блог «Мандрівник».

## Запуск
Відкрийте `index.html` у браузері. Для завантаження Bootstrap, шрифтів і фотографій потрібний інтернет.

## Структура
- `index.html` — головна сторінка;
- `style.css` — стилі;
- `script.js` — фільтрація, пошук, перегляд статей, форма без серверного обробника;
- `posts.json` — дані статей у зручному форматі;
- `placeholder.svg` — резервна ілюстрація;
- `PROMPTS.md` — запити для відтворення роботи з ШІ.

## Перевірка
Перевірте у браузері ширини 375, 768, 1024 і 1440 px (F12 → адаптивний режим), пошук, категорії, відкриття карток, бургер-меню та форму. Форма не надсилає даних на сервер. Для публікації розмістіть усі файли в корені нового публічного репозиторію `web-lab-7`, а в Settings → Pages оберіть main / (root).

Фотографії — зовнішні зображення Unsplash (завантажуються через інтернет). Текст статей створено для навчального макета; наведені маршрути не є перевіреними рекомендаціями щодо поточної доступності чи безпеки.
